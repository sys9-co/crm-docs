    creatorname     varchar(50)   NULL,

    itemcode        varchar(25)   NULL,
    itemname        varchar(255)  NULL,
    qty             money         NULL,
    remainqty       money         NULL,   -- ปริมาณที่ยังไม่ได้ออก SO
    unitcode        varchar(10)   NULL,
    amount          money         NULL,   -- ยอดรวม line item

    department      varchar(60)   NULL,   -- Category Level 2

**Fields สำคัญสำหรับ feature:**

| Field | ใช้ทำอะไร |
|-------|----------|
| `projectcode` | JOIN กับ `crm.projects.code` |
| `iscancel` | filter `iscancel = 0 OR iscancel IS NULL` |
| `amount` | SUM → quotation_amount |
| `remainamount` | SUM → ยอดที่ยังไม่ได้ SO (แสดงเป็น pending) |
| `family/department/category/subcat` | GROUP BY category level |
| `docno` | แสดงรายการเอกสาร |
| `docdate` | เรียงตามวันที่ |

## 3. ตารางใหม่ที่ต้องสร้าง: `project_category_lost_reasons`

**วัตถุประสงค์:** เก็บ lost reason ที่ user ระบุ ต่อ 1 project + 1 category path (text-based)

### 3.1 Columns

| Column | Data Type | Nullable | Default | คำอธิบาย |
|--------|-----------|----------|---------|----------|
| `id` | BIGINT | NOT NULL | GENERATED ALWAYS AS IDENTITY | PK |
| `project_id` | BIGINT | NOT NULL | — | FK → `crm.projects.id` |
| `projectcode` | VARCHAR(30) | NOT NULL | — | denormalized code (ใช้ match กับ history tables) |
| `family` | VARCHAR(60) | NULL | NULL | Category Level 1 |
| `department` | VARCHAR(60) | NULL | NULL | Category Level 2 |
| `category` | VARCHAR(60) | NULL | NULL | Category Level 3 |
| `subcat` | VARCHAR(60) | NULL | NULL | Category Level 4 |
| `lost_reason` | TEXT | NULL | NULL | Free text, max 500 chars |
| `updated_by` | BIGINT | NULL | NULL | FK → `crm.users.id` |
| `created_at` | TIMESTAMPTZ | NOT NULL | NOW() | — |
| `updated_at` | TIMESTAMPTZ | NOT NULL | NOW() | — |

### 3.2 Constraints

| Constraint | Type | Definition |
|-----------|------|-----------|
| `pclr_pkey` | PRIMARY KEY | `(id)` |
| `pclr_project_cat_uq` | UNIQUE | `(project_id, family, department, category, subcat)` |
| `pclr_project_fk` | FOREIGN KEY | `project_id` → `crm.projects(id)` ON DELETE CASCADE |
| `pclr_user_fk` | FOREIGN KEY | `updated_by` → `crm.users(id)` ON DELETE SET NULL |

> **หมายเหตุ UNIQUE:** PostgreSQL treats `NULL = NULL` as false ใน unique index  
> ดังนั้น `UNIQUE (project_id, family, department, category, subcat)` ทำงานถูกต้องเมื่อ NULL  
> — แต่ต้องใช้ `IS NOT DISTINCT FROM` ในการ query เพื่อ match NULL ด้วย

## 4. Query Pattern สำหรับ API

```sql
-- GET /crm/v2/projects/{id}/category-sales-summary
-- Group by family (level 1) — group_level=1

WITH params AS (
    SELECT code AS projectcode FROM crm.projects WHERE id = $project_id
),
quotation AS (
    SELECT
        family, department, category, subcat,
        SUM(CAST(amount AS numeric))        AS quotation_amount,
        SUM(CAST(remainamount AS numeric))   AS quotation_remain
    FROM crm.crm_project_quotation_history, params
    WHERE projectcode = params.projectcode
      AND (iscancel IS NULL OR iscancel = 0)
    GROUP BY family, department, category, subcat
),
saleorder AS (
    SELECT
        family, department, category, subcat,
        SUM(CAST(amount AS numeric))        AS so_amount,
        SUM(CAST(remainamount AS numeric))   AS so_remain
    FROM crm.crm_project_saleorder_history, params
    WHERE projectcode = params.projectcode
      AND (iscancel IS NULL OR iscancel = 0)
    GROUP BY family, department, category, subcat
),
invoice AS (
    SELECT
        family, department, category, subcat,
        SUM(amount)                          AS invoice_amount
    FROM crm.crm_project_invoice_history, params
    WHERE projectcode = params.projectcode
      AND (iscancel IS NULL OR iscancel = 0)
    GROUP BY family, department, category, subcat
),
categories AS (
    SELECT COALESCE(q.family, s.family, i.family)             AS family,
           COALESCE(q.department, s.department, i.department) AS department,
           COALESCE(q.category, s.category, i.category)       AS category,
           COALESCE(q.subcat, s.subcat, i.subcat)             AS subcat,
           COALESCE(q.quotation_amount, 0)                    AS quotation_amount,
           COALESCE(s.so_amount, 0)                           AS so_amount,
           COALESCE(s.so_remain, 0)                           AS so_remain,
           COALESCE(i.invoice_amount, 0)                      AS invoice_amount
    FROM quotation q
    FULL OUTER JOIN saleorder s USING (family, department, category, subcat)
    FULL OUTER JOIN invoice   i USING (family, department, category, subcat)
)
SELECT
    c.*,
    lr.lost_reason,
    lr.updated_at AS lost_reason_updated_at,
    u.name        AS lost_reason_updated_by,
    CASE
        WHEN c.invoice_amount > 0                             THEN 'win'
        WHEN c.so_amount > 0 AND c.invoice_amount = 0        THEN 'draw'
        ELSE                                                       'lose'
    END AS status
FROM categories c
LEFT JOIN crm.project_category_lost_reasons lr
    ON  lr.project_id  = $project_id
    AND lr.family      IS NOT DISTINCT FROM c.family
    AND lr.department  IS NOT DISTINCT FROM c.department
    AND lr.category    IS NOT DISTINCT FROM c.category
    AND lr.subcat      IS NOT DISTINCT FROM c.subcat
LEFT JOIN crm.users u ON u.id = lr.updated_by
ORDER BY c.family, c.department, c.category, c.subcat;
```

## 5. Category Hierarchy

```
family       → ระดับที่ 1  (เช่น "ห้องครัว", "ระบบไฟฟ้า")
  department → ระดับที่ 2
    category → ระดับที่ 3
      subcat → ระดับที่ 4
```

**group_level parameter:**

| group_level | GROUP BY | ตัวอย่าง |
|-------------|---------|---------|
| 1 (default) | `family` | แสดงแค่ level 1 |
| 2 | `family, department` | |
| 3 | `family, department, category` | |
| 4 | `family, department, category, subcat` | รายละเอียดสุด |
